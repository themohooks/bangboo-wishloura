# Go Client — flutter_vpn_go

This directory contains the shared Go VPN core module.  
It is compiled via **gomobile bind** and consumed as:
- `goclient.aar` on Android  
- `GoClient.xcframework` on iOS

---

## Prerequisites

### 1. Install Go 1.21+
```bash
# macOS
brew install go

# or download from https://go.dev/dl/
```

### 2. Install gomobile
```bash
go install golang.org/x/mobile/cmd/gomobile@latest
go install golang.org/x/mobile/cmd/gobind@latest
# Ensure $GOPATH/bin (or $HOME/go/bin) is on your PATH
```

### 3. Initialize gomobile (once per machine)
```bash
gomobile init
```

### 4. Android NDK (for Android builds)
- Install via Android Studio: **SDK Manager → SDK Tools → NDK (Side by side)**
- Set `ANDROID_NDK_HOME`:
```bash
export ANDROID_NDK_HOME=$HOME/Library/Android/sdk/ndk/25.x.x
```

### 5. Xcode 15+ (for iOS builds)
```bash
xcode-select --install
```

## Build Android AAR

```bash
cd flutter_vpn_go/go_client
./build_android.sh
```

Output: `android/vpnplugin/libs/goclient.aar`

Manual command:
```bash
gomobile bind \
  -target=android \
  -androidapi 26 \
  -o ../android/vpnplugin/libs/goclient.aar \
  ./client
```

---

## Build iOS XCFramework

```bash
cd flutter_vpn_go/go_client
./build_ios.sh
```

Output: `ios/Frameworks/GoClient.xcframework`

Manual command:
```bash
gomobile bind \
  -target=ios \
  -o ../ios/Frameworks/GoClient.xcframework \
  ./client
```

## Connect Android AAR

In `android/vpnplugin/build.gradle`:
```gradle
dependencies {
    implementation fileTree(dir: 'libs', include: ['*.aar', '*.jar'])
}
```

In code (`GoClientBridge.kt`):
```kotlin
import client.Client          // generated by gomobile
import client.Version
```

---

## Connect iOS XCFramework

1. Open `ios/Runner.xcworkspace` in Xcode.  
2. **Runner target → General → Frameworks, Libraries, Embedded Content:**  
   - Click `+` → Add Other → Add Files  
   - Select `ios/Frameworks/GoClient.xcframework`  
   - Set to **Embed & Sign**
3. **PacketTunnel target → General → Frameworks and Libraries:**  
   - Add `GoClient.xcframework`  
   - Set to **Do Not Embed**
4. In Swift code:
```swift
import GoClient   // generated by gomobile
let version = ClientVersion()
```

## Public API

```go
// Create and configure
client := client.NewClient()
client.SetLogger(myLogger)  // implement client.Logger in Kotlin/Swift

// Start (configJSON = full TunnelConfig JSON)
err := client.Start(configJSON)

// Packet bridge (called by native TUN loop)
err = client.WritePacket(pkt, 4)   // 4=IPv4, 6=IPv6
pkt, err = client.ReadPacket()

// Stats
statsJSON := client.StatsJSON()    // JSON string

// Status
status := client.Status()          // "connected" | "disconnected" | ...

// Stop
client.Stop()

// Version
v := client.Version()
```

## gomobile API constraints

> Read before modifying the public API.

- ✅ Exported types: `string`, `bool`, `int`, `float64`, `[]byte`, `error`
- ✅ Exported structs with fields of the above types
- ✅ Exported interfaces (methods with above types only)
- ❌ No generics in exported API
- ❌ No `chan`, `map`, complex struct hierarchies in exported API
- ❌ No multiple return values except `(T, error)`
- ✅ Config passed as JSON string to avoid slice/map limitations
